PROG6112/w - EXAM SOLUTION
=======================

HOW TO USE:
1. Extract this zip.
2. You have 2 separate projects - DO NOT mix them (both use ProductSales class name).

Question1_ConsoleApp:
- Create a new Java project in NetBeans / IntelliJ
- Copy src/q1/*.java into src/q1/
- Copy test/q1test/*.java into test/q1test/ (add JUnit library)
- Run ProductSalesReport.java
- Expected output:
  PRODUCT SALES REPORT - 2025
  Total sales: 2200
  Average sales: 367
  Maximum sale: 700
  Minimum sale: 150

Question2_GUIApp:
- Create a new Java project
- Copy src/q2/*.java into src/q2/
- Copy test/q2test/*.java into test/q2test/ (add JUnit library)
- Run ProductSalesGUI.java
- Click Load Product Data -> shows Total 2200, Average 367, Over 2, Under 4, Years 2
- Click Save Product Data -> creates data.txt in project folder
